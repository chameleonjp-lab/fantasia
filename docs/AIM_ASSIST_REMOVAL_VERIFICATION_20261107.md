# 2026-11-07 操縦・射撃・表示の分離

通常の出撃で使う `main.ts → CampaignFlightController → Campaign.step` を変更した候補です。両モードの操縦は敵の配置・種類・発射状態に依存せず、通常弾は左右の銃口から機首の正面へ出ます。Easy は移動後の姿勢、実際の画面比、円内・1.2km・地形遮蔽で発射可否だけを判定します。兵士、ドラゴン、砲台への追尾と画面外倍率を外しました。Normal は手動長押しです。巡航・速度感度・NPC射撃・爆弾・戦役・得点・保存先・配信設定は変更対象にしていません。

操縦中の指・キーが中央でも機首角を保ち、離した後だけ水平へ戻します。高さだけの表示変更では指と入力を保持し、次の座標を引き継ぎます。回転、幅変更、離脱、停止は入力を解除します。開始準備中の表示変更は、古い画面の完了通知を採用せず再準備します。

表示は直前と現在の固定tickを同じ割合でつなぎ、自機・カメラ・対象・照準表示に使います。発射、命中、時計は確定状態のままです。表示側の照準色は補間された対象から判定し、確定tickの発射対象IDで制限しません。開始、停止再開、復活、世代変更では古い姿勢を混ぜません。
